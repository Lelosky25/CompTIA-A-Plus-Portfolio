# Connecting a Desktop

## Objective

Connect a desktop computer's main components and power it on successfully.

## Equipment

* System unit
* Monitor
* Keyboard
* Mouse
* HDMI-to-VGA cable
* USB-A connectors
* Power cables
* Wall power panel

## Procedure

### Step 1 — Connect the Monitor to the System Unit

The monitor was connected to the system unit using the HDMI-to-VGA cable.

**Connection:**

`System Unit → HDMI-to-VGA Cable → Monitor`



---

### Step 2 — Connect the Keyboard and Mouse

The keyboard and mouse were connected to available USB-A ports on the system unit.

**Connections:**

`Keyboard → USB-A → System Unit`

`Mouse → USB-A → System Unit`



---

### Step 3 — Connect Power

Power cables were connected from the monitor and system unit to the wall power panel.

**Connections:**

`Wall Panel → Power Cable → Monitor`

`Wall Panel → Power Cable → System Unit`


---

### Step 4 — Start the Desktop

The monitor and system unit were powered on.

The monitor displayed the computer's output, and the keyboard and mouse were tested to verify that the system was responding to input.


## Result

The desktop was successfully connected and powered on. The monitor displayed the system output, and the keyboard and mouse provided input to the computer.
