# CMIT 202 – CompTIA A+ Portfolio

## About
This repository documents my progress throughout **CMIT 202: Fundamentals of Computer Troubleshooting** at the University of Maryland Global Campus (UMGC).

The purpose of this repository is to track my learning, document hands-on labs and projects, record troubleshooting experiences, and build a portfolio that demonstrates my foundational IT knowledge while preparing for the CompTIA A+ certification.

- Complete all CMIT 202 coursework
